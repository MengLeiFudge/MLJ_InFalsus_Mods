# 更新记录

## 1.0.1

- 成绩页顶部仅显示 PTT、B10、B50，移除标题、MAX 和常驻说明，关闭按钮改为右上角红叉。
- 搜索框与操作按钮按实际字形范围居中；滚轮直接调整列表位置，滚动条底板、轨道与滑块使用独立深度。
- 成绩卡片与 B50 分享图共用绘制函数，统一圆角、字号、字体和文字位置，并按视口裁切整张卡片。
- 修复退出选歌时重复注销已销毁头像/PTT 按钮产生的 ArgumentNullException。
- 头像与 PTT 入口改用独立原生按钮，直接登记最终菱形碰撞体；移除对入口布局矩形的重复鼠标裁切，保留游戏边界和弹窗输入隔离。
- 按 Arcaea 原始布局调整头像、徽章比例和右下重叠位置；账号数字采用 Exo-SemiBold，整数与小数按 34:24 分层，并共同适配宽度。
- 选中谱面信息移至独立深色成绩区，与返回按钮分隔；补全难度、定数、单曲 PTT、排名、打击分数、完成等级、纪录时间与定数来源。
- 侧卡文字按单曲 PTT 档位配色，保留现有定数和排名显示。

- 萌泪酱定数升级为 v6，内置当前 320 个谱面结果及四难度独立模型。新谱面在后台读取本机文件并离线计算，无需 Python 或联网；已计算结果保存至当前 profile。
- 萌泪酱结果限制在官方等级范围内：低于 7 级分 .0/.5，7、8 级分 .0/.5/.8，9 级及以上每 0.1 一档。
- 安小璃更新与萌泪酱计算全部结束后，选歌空闲时统一弹一次变化数量提示；全部无变化时不弹窗。请求或计算失败保留本地定数，互不阻塞另一来源的结果。
- 萌泪酱缓存按内置表和模型指纹隔离；官方等级改变后重新计算，单次后台计算最多两分钟。
- 兼容旧 menglei-v4 成绩文件，切换来源或采用新定数后重算潜力值与排名，保留原始成绩和取得时间。

- 安小璃定数改为从 In Falsus Tools 的 experimental.json 获取，每次启动后台检查一次，15 秒超时；失败时沿用本地定数。
- 更新 DLL 内置定数副本，并在当前 profile 保存下载缓存；模组更新内置表后，旧缓存不会覆盖新表。
- 定数更新后同步重算潜力值、排名、排序和分享图数据，保留原始成绩与取得时间。
- 修复侧卡布局范围为零或尚未就绪时导致整个选歌潜力值界面停用：文字行使用独立定位点，保留原有位置、字宽和卡片缩放。

## 1.0.0

- 适配游戏1.0.7的选歌排序回调，保留原版与潜力值扩展排序的切换。
- 新增潜力值系统，直接读取当前可用谱面；内置安小璃与萌泪酱两份各300条的固定定数表，缺项回退歌曲等级。
- 在原生“游戏和 UI 设置”增加“潜力值系统”分类及“谱面定数来源”左右箭头选项：官方等级、安小璃、萌泪酱，默认安小璃，选择保存在当前 profile；官方等级直接作为定数，所有来源始终显示一位小数。
- 按新版 B50/B10 固定分母 60 计算账号 PTT，并保留每谱面最高表现。
- 从逐局 history 计算每谱面最高 PTT，分数与完成等级来自同一次游玩；完成等级达到 DiveCleared 时增加 0.2。
- 在原版存档旁保存 savestate_ptt_v1.json，记录真实最佳成绩及已知时间；随历史变化同步，兼容旧整数数据。切换定数来源重新计算全部数值与排名，保留原始成绩和时间。
- 选歌顶部显示放大的所选角色头像菱形，上角裁至游戏边缘，右下小菱形显示 PTT；白色头像边框采用 Arcaea APK 素材，配合深色菱形底。
- 歌曲卡片未游玩时显示 `10.0`，已游玩时显示 `#10 11.1 -> 11.123`；侧卡信息位于曲绘上方，使用单层文字；选中谱面信息位于场景左下。
- 徽章按固定潜力值门槛 0/4/8/11/12/13/13.5/14 切换，13、13.5、14 分别对应一星、二星、三星；选歌、结算、完整成绩页和 B50 导出使用同一规则。
- 点击顶部头像或 PTT 菱形浏览全部已游玩谱面的最佳成绩，支持封面卡片、滚动和搜索；入口复用原生按钮并在选歌取得输入后重新登记，按头像和 PTT 的独立菱形设置碰撞范围，并限制在游戏显示区域内，弹窗期间禁用入口。
- 原版排序按钮切换序列依次加入“歌曲定数 升序／降序”“歌曲潜力值 升序／降序”：前者使用当前来源定数，后者使用最佳单曲 PTT；沿用原生按钮及双向循环，保留全部原版排序选项。
- 新增 B50 分享图片生成与剪贴板导出，采用五列横向圆角卡片；成绩页与分享图均使用曲绘的深色印象色，标明当前谱面定数来源，不依赖屏幕截图或当前窗口分辨率。
- 结算信息位于顶部中央，左侧显示单曲变化，右侧显示账号增加值或 Keep，保留账号数值过渡动画。
- 独立成绩文件采用原子替换和上一版备份；读取与写入失败均明确提示。
- 修复选歌和结算文字副本清空原生材质缓存导致的空引用异常，保留原生字体组件的初始化与回收流程。
- 成绩页改用游戏原生字体、按钮、滚动列表与垂直滑块，统一点击和拖动输入，避免当前 IL2CPP 版本中 GUI 接口恢复不完整的问题。
- 命中范围按原生布局的累计相机深度换算，统一顶部头像入口及成绩页控件的投影依据。
- 修复头像容器实际尺寸为零导致点击无响应：固定尺寸容器按父级比例参与原生布局，Best 页直接换算可用范围，按钮和滚动视口同步获得有效命中区域。
- 修复进入选歌时报“原生 UI 容器的布局范围尚未就绪”：尺寸换算与点击范围直接读取原生布局缓存，避免 IL2CPP 引用返回值导致布局数据读取错误。
- 成绩页以游戏原生显示区域布局并裁切列表边缘，在 16:10 屏幕上保持在游戏 16:9 区域内；关闭时注销本页控件并归还选歌输入。
- 修复两侧歌曲卡片误用未同步的难度字段：定数、已游玩成绩、排名和潜力值排序均按原生歌曲行的实际难度查询。
- 设置页将新增分类高度计入内容边界，同步原生滑块长度、位置和拖动映射，使底部定数来源选项行能够完整滚入游戏区域。
- 修复搜索聚焦后不接收文字：原生输入接收器在登记及释放时稳定声明文字监听，焦点只控制文本写入。
- 内嵌 NotoSansCJKsc 字体补全中文显示，设置页显示“萌泪酱”，导出提示使用“粘贴”。
- Best 页面与导出卡片共用宽高、列数及间距，封面、文字和行高等比缩放；页头信息、操作按钮和状态提示分区显示。
- 头像与 PTT 使用独立菱形碰撞体，自有命中层置于原生顶部遮挡层之前；鼠标进入可见入口时重放原生悬停判定。
