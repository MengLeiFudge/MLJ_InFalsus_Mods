# v6 定数计算

v6 为四个难度分别保存模型，结果限制在官方整数等级 L 内，并按以下档位输出。PotentialSystem 1.0.1 已嵌入冻结模型、当前 320 张结果及 C# 读谱/特征提取程序，启动后只后台计算未收录或等级改变的谱面。

| 官方等级 | 合法定数 |
| --- | --- |
| L < 7 | L、L+0.5 |
| L = 7 或 8 | L、L+0.5、L+0.8 |
| L ≥ 9 | L、L+0.1、…、L+0.9 |

取同级最近档位，等距时取较高档，不允许进位到下一等级。内部保留连续估计，表中同时列出连续值和最终定数。粗分档会增加并列，且本级顶部的估计会向下归档；不强求各档数量均匀。

## 文件与使用

- `../chart-constants-v6.xlsx`：当前 320 张谱面，包括 20 张新增谱面；另有趋势、偏差、反向谱面对和说明工作表。
- `chart-constants-v6.csv`：同一份完整定数表。
- `generate.py`：按难度拟合、比较两种固定候选、核对当前游戏谱面内容并导出。
- `v6_model.py`：冻结模型的纯标准库推理；`predict(model, row)` 返回连续估计、最终档位及所用方法，`quantize` 执行分档。
- `model.json`：四套完整参数，普通 JSON 53921 字节；紧凑序列化约 29.5 KB，gzip 约 11.4 KB。
- `training-data.json`：旧 300 张训练资料的必要特征与原始社区标签，包含 116 张细分参照。
- `results.json`：当前谱面特征、摘要、预测、候选指标及输入版本记录。
- `export_runtime.py`：把已有 `results.json` 导出为 `Assets/MengLeiConstants.json`；仅转换发布数据，不重新训练，目标存在时拒绝覆盖。

完整重算在仓库根目录执行：

```bash
OPENBLAS_NUM_THREADS=1 python3 -B PotentialSystem/Assets/定数测量/v6/generate.py
```

生成器使用本机 `.codex/chart-constant-estimation` 的既有解码器、特征提取程序、依赖缓存及游戏资源。它会拒绝覆盖已有模型、JSON、CSV 或 v6 工作簿；重算前先把这些生成产物归档。v4/v5 文件及旧训练缓存始终保留。

纯推理只需要 `v6_model.py`、`model.json` 和已按对应口径提取的谱面特征，不需要 NumPy、SciPy、游戏进程或网络。游戏内对应实现位于 `PotentialSystem/src/ChartDecoder.cs`、`KeyboardWorkload.cs`、`ChartMotion.cs`、`ChartFeatures.cs` 和 `MengLeiModel.cs`。`MengLeiConstants` 负责游戏数据的主线程快照、后台计算与 profile 缓存；游戏运行时不调用 Python 或研究工具。C# 移植通过静态对照和 Windows Release 编译，尚未进行游戏内验收或跨语言运行结果对照。

## 四个难度的计算

MIN、EVO 各自使用旧研究选出的四项特征，非负最小二乘拟合结构等级，并减去本难度同官方等级的中心值。连续定数为 `L + 0.45 + 结构等级偏离`，偏离保持等级单位，缩放系数固定为 1，不借用 ULT/FBD 参数。MIN 更关注键盘峰值、天上操作峰值、操作密度和重复折扣；EVO 更关注键盘峰值、滑键精度、两手同步和按键密度。由于没有细分参照，这是结构估计，不能宣称小数准确。

ULT、FBD 分别比较既有结构公式与 v5 七项特征的“线性岭回归 + RBF 核岭回归均值”。按歌曲留一时，本难度中同一首歌的资料全部移出训练；优先选择同级排序趋势更一致的候选，趋势相同时再比较绝对误差。两者均选择了独立回归模型，训练、标准化、权重和核中心没有混合。ULT 社区回归覆盖训练中的 10～12 级，FBD 覆盖 10～14 级；其余等级使用该难度自己的结构公式。没有同级结构中心时取 L+0.45，再按合法档位输出。

原 v5 的七项特征为键位切换、节奏变化峰值、键盘负担、Sky 局部跳位、Sky 被迫跳位、Sky 必需移动和和弦重复率。v6 保留固定特征和正则强度，没有进行大范围参数搜索。现有特征本身经过旧资料选择，本次两种候选又通过同一批留一结果选择，所以留一指标仍不是完全独立的外部验证。

训练冻结旧 300 张资料，使用 In Falsus Tools 原值，不使用 feedback 修订。当前安小璃 JSON 用于对照，不将 20 张新谱面加入训练。旧谱面的解码摘要与缓存一致才复用特征；本次旧 300 张摘要一致，20 张新谱面重新读谱。

## 趋势与差异

主要评价同一难度、同一官方等级内的趋势。社区值相同的谱面对不计入比较；模型并列计半。跨等级的趋势受硬边界保证，不能用来证明模型有效。

下表使用相同的旧 116 张细分参照，均先量化到最终一位小数后统计：

| 方法 | 平均绝对差 | 同级趋势一致率 | 差超过 0.3 |
| --- | ---: | ---: | ---: |
| v5 保存的按歌曲留一结果 | 0.1328 | 79.11% | 6 |
| v6 按歌曲留一结果 | 0.1293 | 79.71% | 7 |
| v6 全资料直接预测 | 0.1060 | 85.51% | 1 |

v6 留一按难度分开：ULT 为 86.74% / MAE 0.0905，FBD 为 73.92% / MAE 0.1514。直接预测包含参与拟合的谱面，不能当作新谱面精度。这里对 v5 的统计经过一位小数量化，与旧研究直接统计连续值的 0.129 及离群数不是同一口径。

对当前安小璃表，排除超出当前官方等级的冲突项后，ULT 同级一致率 80.47%、MAE 0.1785；FBD 同级一致率 74.81%、MAE 0.1570。这是当前表对照，包含训练中已有的谱面，不是独立泛化成绩。MIN/EVO 的社区值在可比同级组中没有细分差异，无法计算有意义的同级趋势一致率。

与 v5 工作簿共有的 117 张中，91 张保持不变、26 张相差 0.1，没有更大的变化。与 v4 共有的 300 张中，210 张变化，平均绝对变化 0.13，最大 0.7；其中包含新分档和边界收紧的影响。

最终分档数量：低于 7 级 138 张（.0 为 38，.5 为 100）；7、8 级 30 张（.0 为 11，.5 为 11，.8 为 8）；9 级及以上 152 张，均属于 .0～.9 的十分档。
