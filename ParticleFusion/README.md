# ParticleFusion

为 In Falsus 的粒子库存增加智能融合与选中材料融合。

## 使用

库存“批量选择”上方会出现融合按钮：

- 普通模式自动选择可用材料。
- 批量选择模式只使用玩家选中的粒子作为材料。
- 点击后使用游戏原版窗口显示简要预览和预计结果（分解颗数、新增满效能颗数），确认后才会修改库存。
- 智能模式可通过 `-` / `+` 按钮调整材料上限，左右方向键可逐颗微调；预计结果随上限实时更新，与确认后的实际结果一致。

融合会把可用粒子强化到满效能，即该粒子（同种类、同技能组合）在已解锁回想掉落表中的最高效能；上限为 999 的粒子就是强化到 999。优先强化离上限最近、费用最低的粒子，使每颗成品消耗的材料尽量少。智能模式以距上限 99 为界：距上限 99 以内的粒子只被强化、不会被分解，更低的粒子只作为材料。满效能和三技能粒子不会被分解，材料技能不会转移到成品。材料不足时不会执行不完整的强化，剩余效能会保存在实际粒子中。

模组只生成当前进度能够直接获得的合法粒子组合，并会顺带整理可以安全合并的库存条目。确认窗口和结果窗口只显示操作概要，详细诊断仅写入 BepInEx 日志。

## 安装

建议通过 In Falsus 的 Thunderstore/r2modman 安装。依赖中的 BepInExPack_IL2CPP 会由模组管理器处理，本包不携带 BepInEx、Doorstop 或 .NET 运行时。插件文件名为 `ParticleFusion.dll`。

界面支持简体中文、繁体中文、英语、日语和韩语。

## 兼容范围

当前适配 Steam App ID 3971950、Unity 6000.3.9f1 和 IL2CPP 元数据版本 39。每次执行融合前都会核对粒子结构、库存状态和当前可用来源；校验失败时不会修改库存。
