# 最后四个回想各刷 20 次：一次智能融合的库存变化

离线随机样本。掉落按原生规则与真实资源生成，融合直接调用当前正式源码（FusionEngine、TraitConsolidator 等）；没有读取或修改真实存档，也没有启动游戏。

## 场景条件

- 从空库存开始；四个回想各通关 20 次，全部刷完后执行一次智能融合，材料上限为默认值（全部效能低于 900、可分解的材料，2,619 颗）。
- 31 个可重复回想全部解锁；五星通关，额外数量倍率 100%，不计首通奖励。
- 掉落加成：额外抽取 3 次、每组 1～10 颗、最低效能为上限的 25%、5% 概率直接满效能。最低效能按整数截断，其余效能为最低值 + round((999−最低值)×U^(1/3))。
- 同一次抽取的整组粒子共享技能和效能；形状按同阶级轮换排除，状态跨 20 局保留。
- 掉落种子 20260923，使用 .NET 8 System.Random，可复现此样本，但不复现 Unity 某一局的随机序列。融合算法不含随机性。

## 算法对比

同一份融合前库存、各自默认材料上限下，旧算法（999 最少的种类优先、低效能目标也会强化、全部未满粒子都可作材料）与当前算法（按强化费用从低到高；效能 900 以上只作目标，低于 900 只作材料）的结果：

| 指标 | 旧算法 | 当前算法 |
| --- | ---: | ---: |
| 默认材料上限 | 4,010 | 2,619 |
| 分解颗数 | 3,337 | 2,615 |
| 新增 999 颗数 | 743 | 1,229 |
| 每颗新增 999 的分解颗数 | 4.49 | 2.13 |
| 融合后库存 | 1,075 | 1,797 |
| 融合后 999 总数 | 1,035 | 1,521 |
| 实体余料 | 40 颗 / 20,374 点 | 1 颗 / 183 点 |
| 规划与整理耗时 | 670 ms | 37 ms |

耗时为离线 .NET 8 单次测量（Windows，Release），只反映相对量级，不代表游戏内 IL2CPP 环境的毫秒数。确认窗口的预估（只规划、不整理）单次 23 ms。

门槛取值在同一样本上的比较（其余规则相同，上限均为默认值）：

| 门槛 | 默认上限 | 分解 | 新增 999 | 每颗分解 | 融合后库存 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 800 | 1,682 | 1,681 | 953 | 1.76 | 2,731 |
| 850 | 2,067 | 2,066 | 1,076 | 1.92 | 2,346 |
| 900 | 2,619 | 2,615 | 1,229 | 2.13 | 1,797 |
| 925 | 2,955 | 1,894 | 1,075 | 1.76 | 2,518 |
| 950 | 3,295 | 723 | 724 | 1.00 | 3,689 |

门槛越低，可强化的目标越少；门槛越高，单颗目标越便宜但目标数量也越少。900 在本样本中新增 999 最多，单颗消耗约为旧算法的一半，当前取 900。另一种做法是允许 900 以上的粒子互相供能：本样本中新增 999 多 39 颗（1,268），但分解多 149 颗、每颗 2.18，且边际约 4.1 颗换 1 颗 999，因此未采用。

## 明细和复现

- drops.csv：每个回想、每一局、每次抽取的整组粒子。
- before.csv、after.csv：完整堆叠库存，含形状、数量、效能、技能编号和中文名。
- summary.json：全部条件、汇总、每种形状和每个技能的数量。
- source-hashes.json：本次模拟对应的正式源码、离线程序及输入 SHA-256。

从 ParticleFusion 目录运行：

```powershell
dotnet build tools/FusionSimulation/Simulation.csproj -c Release
dotnet tools/FusionSimulation/bin/Release/Simulation.dll tools/FusionSimulation/input.json reports/fusion-last-four-20
```

离线程序链接正式融合源码；GameModel 只提供与游戏 interop 字段偏移一致的数据容器。程序会核对本次输出的颗数守恒、效能守恒、每颗完整来源合法性，以及确认窗口预估与实际执行的一致性，任一不符即终止。游戏内的 UI、读档和库存提交未在此验证。

## 掉落规则的静态依据

- ResultsScene.Start RVA 0x71FE30：按 EncounterDetail.LootTableIndex 读取粒子表及技能表；0x722028/0x72202C 为技能表读取路径。
- _c._C RVA 0x47D090、IotaDropTableState._SPA RVA 0x4B66F0：加权形状抽取和按阶级重置轮换排除。
- _c._d RVA 0x47D320：25% 最低效能、立方根抽样、5% 满效能和按技能表行去重。
- IotaInstance.TraitCount RVA 0x4A6580：返回 3−(raw & 3)。
