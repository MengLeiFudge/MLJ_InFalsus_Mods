# Changelog

## 1.0.1

- 适配游戏 1.0.6：入口图案改为托管侧解码，修复新版 interop 下入口按钮无法创建、按钮消失的问题。
- 只选等级、不选特性时也会筛选材料，显示携带任一所选等级特性的粒子。
- “特性筛选”入口文字与原版“全部”文字对齐。

## 1.0.0

- 首个公开版本。
- 支持特性多选、“包含任意特性 / 包含全部特性”匹配以及精确等级多选；等级未选与全选等价。
- 借用当前制卡场景中已初始化的完整原版配方筛选浮窗，保留背景、边框、关闭动画和输入所有权。
- 浮窗标题为“特性筛选”，加宽侧栏提供“等级”、匹配方式及居中的重置按钮。26 个特性族按伤害、回复、增益、减益分四行展示，类别标题靠近对应图标并垂直居中，范围与非范围特性相邻。
- 方形按钮中显示带触发条件标记的原版六边形特性图标，常显名称字号增大；开幕、终幕、周期等条件通过外框区分。
- 悬停使用原版 TraitIconHoverContainer 资源显示各实际等级的游戏本地化效果，离开或关闭后隐藏，不占用按钮输入。
- “特性筛选”入口紧邻紫色按钮，沿用“有特性”图案和原版图文对齐，移除模式状态块。恢复可点击时同步刷新悬停登记，单击后在下一帧取得浮窗输入。
- 技能选择入口在所有原版筛选模式下均可打开；已选技能只在“全部”和“有特性”模式下参与材料筛选。
- 技能图标与宿主浮窗使用同一渲染层，保持普通态和选中态的图像可读性。
- 材料列表的形状、数量、效能及展开明细统一读取技能筛选结果；选择变化时正确刷新已展开的粒子定义。
- 修正中文 Windows 上 BepInEx IL2CPP 控制台的 UTF-8 显示。
- 发布包采用 Thunderstore 标准结构，不携带 BepInEx 或运行时文件。
