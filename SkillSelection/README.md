# SkillSelection

为 In Falsus 的制卡界面增加独立的技能选择入口。筛选只建立当前材料列表的只读视图，不修改真实库存，也不会移除棋盘上的材料。

## 使用

制卡界面中，紫色按钮右侧紧邻“特性筛选”按钮，使用原版“有特性”图标，不显示模式状态块。在任何原生筛选模式下，单击入口都可打开并修改选择。只有原生筛选为“全部”或“有特性”时，已选技能条件才会参与材料筛选。弹层借用当前制卡场景中已经初始化的完整配方筛选浮窗，居中显示；背景、边框、ESC、背景阻挡、关闭按钮和开关动画均沿用游戏行为。

原版筛选浮窗中的控件支持：

- 按伤害、回复、增益、减益分四行完整展示 26 个特性族，范围版紧邻对应的非范围版。点击多选，再次点击取消。
- 每项保留原版方形选中框，内部显示带触发条件标记的完整六边形图标；下方常显放大后的当前语言名称。
- 鼠标悬停时显示原版特性说明浮窗，列出该特性实际存在的各等级效果；说明读取游戏当前语言的数据。
- 选择“包含任意特性”或“包含全部特性”。
- “等级”支持独立多选 I、II、III。未选和全选都不限制等级；部分选择只匹配所选等级，例如 I + III 不会匹配 II。部分特性只有 III 级，按实际等级参与筛选。
- 使用原版重置按钮清空全部附加条件。

零项选择不会增加限制。切换到其他原生筛选模式时，技能条件暂时停用；切回支持模式后恢复。退出制卡界面时会清除选择。游戏已有的颜色、形状和特性条件继续与技能条件叠加。

筛选同时作用于形状列表、数量、效能和展开明细，均按每颗粒子实际携带的技能及其等级计算。数量和效能只统计匹配粒子的原有堆叠数量；正在棋盘上使用或拖拽的粒子不受影响，真实库存始终保持不变。

## 安装

建议通过 In Falsus 的 Thunderstore/r2modman 安装。依赖中的 BepInExPack_IL2CPP 会由模组管理器处理，本包不携带 BepInEx、Doorstop 或 .NET 运行时。插件 DLL 名为 `SkillSelection.dll`，可与 ParticleFusion 分别启用或停用。

界面支持简体中文、繁体中文、英语、日语和韩语。技能译名读取游戏当前语言的 DynamicStringMapping，不建立独立的翻译身份。

## 兼容范围

当前适配 Steam App ID 3971950、Unity 6000.3.9f1 和 IL2CPP 元数据版本 39。游戏元数据变化时模组会记录提示并继续加载；筛选准备失败时会清空附加条件并恢复原生列表，不会把异常带过原生回调边界。
